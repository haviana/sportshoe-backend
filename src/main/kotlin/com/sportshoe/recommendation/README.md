# recommendation module

This package is a placeholder for the recommendation engine described in
`RECOMMENDATION_ENGINE.md`. It currently contains only the output data shapes
(`RecommendationModels.kt`) so other modules can compile against a stable contract.

Explicitly NOT implemented yet (by design, per current project scope):
- Candidate filtering
- Weighted rule scoring
- Explanation generation
- Ranking
- Free-text signal extraction
- Any AI/ML integration

These will be added in a subsequent increment.
